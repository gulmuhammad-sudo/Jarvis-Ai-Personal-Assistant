# Personal Assistant 1.28.0

A personal AI assistant for Windows: it talks, listens and gets things done on your PC, in English, Urdu or almost any language. Free.

## Download and install

| File | For whom |
|---|---|
| **`Personal-Assistant-Setup.exe`** | everyone: the one file you need |
| `Personal-Assistant-1.28.0.zip` | the same Setup in a folder with the instructions (if your browser blocks `.exe` files) |
| `SHA256.txt` | to check the download (optional) |
| *Source code (zip / tar.gz)* | developers only: **there is no app inside** |

1. Open `Personal-Assistant-Setup.exe`. If Windows says *"Windows protected your PC"*, press **More info → Run anyway** (the app isn't code-signed).
2. Press **Next** through the steps (every step already has a good answer), then **Install** and **Finish**. No admin password needed.
3. Open **Personal Assistant** from the Desktop or the Start Menu.

Windows 10 (1809 or newer) or 11, 64-bit. Updating: run this Setup; your settings, memories and keys stay. Problems: [Install help](https://github.com/gulmuhammad-sudo/Jarvis-Ai-Personal-Assistant/blob/main/docs/INSTALL.md).

**Urdu:** `Personal-Assistant-Setup.exe` download karke kholein. Windows roke to **More info → Run anyway**. Phir Next dabate jayen. *Source code* wali file mein app nahi hoti.

## New in 1.28.0

- **Learn:** flashcards that come back just before you would forget them. Study with the mouse, the keyboard or by voice ("quiz me"); import from text, CSV or Anki.
- **Fitness:** water, steps, sleep, weight and workouts, with daily targets, charts and reminders. Private: the assistant can't read it until you allow it.

## If you come from 1.7.1


- **A new look:** glass panels everywhere, light and dark.
- **Daily page:** timers that survive a restart, stopwatch, focus rounds, alarms that ring until stopped, world clock, and news with your own sources.
- **Planner:** calendar, tasks, notes, goals and habits, a private journal, your own record of money, and Gmail (reading and drafts; it can't send).
- **Documents:** reads and makes Word, Excel, PowerPoint and PDF, and searches inside the folders you choose.
- **Voices:** Pakistani voices, men's and women's; voices and speech recognition that work offline on your PC (optional downloads).
- **Agents, automations and plans:** specialists, routines, and longer tasks shown step by step. Local AI with Ollama if you want.
- **Windows and PC care:** windows side by side, workspaces, app updates through winget, internet check.
- **Safer:** approvals per kind of action (Ask / Allow / Never), encrypted keys, Emergency Stop, text from the web never counts as an instruction.
- **Setup:** an update never leaves you without a working app, clear messages when something is missing (WebView2, free space), and a picture while it unpacks.
